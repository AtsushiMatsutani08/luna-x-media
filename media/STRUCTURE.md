# Media structure

- `media/luna/reference/` — LUNA approved identity masters
- `media/luna/generated/` — LUNA generated media
- `media/luna/posts/` — LUNA published/post assets
- `media/yuna/reference/` — YUNA approved identity masters
- `media/yuna/generated/` — YUNA generated media
- `media/yuna/posts/` — YUNA published/post assets

Legacy LUNA files currently at `media/luna-*` are legacy-only and must not be used by YUNA. New LUNA assets must use `media/luna/`. Persona guard is defined in `media/persona-guard.json`.
