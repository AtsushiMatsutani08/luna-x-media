# LUNA 固定参照セット v1.0

## 目的
今後のLUNA投稿画像で、ユーザー承認済み4枚を実際の画像入力に使用する。

## 前提
主参照は luna-reference-02.jpeg（白Tシャツの単独セルフィー）。
01は日常の16コマ、03は朝の9コマ、04は朝の4コマ。補助画像のコラージュ構成・文字は通常投稿へコピーしない。
4枚は元JPEGのまま保持。YUNAや未承認の生成画像と混同しない。

## 制約
生成前に主参照および必要な補助画像を取得し、画像を開いて確認する。
image_genでは取得したローカル実体を referenced_image_paths に渡す。URLや文章の特徴だけで代用しない。
取得に失敗したらLibrary原本IDから再取得する。いずれも取得できない場合は生成・公開を止め、原因を具体的に報告する。
原本・参照定義の変更にはユーザーの新たな指定が必要。生成結果を参照マスターへ自動昇格させない。
自然な肌、眉、目、鼻、唇、顔の輪郭、髪の根元とハイライトを参照。過度な美肌化や別人化を避ける。
生成AIによる顔の完全一致は保証できない。生成後に原本と並べて視覚確認し、明らかな違いがあれば再生成する。照合数値や確認実績を捏造しない。
写真は通常1枚。時間帯・服装・行動・照明を本文に合わせ、直近の角度・目線・手の位置を繰り返さない。
参照画像を実際に渡せた事実と、生成後の品質確認を分けて記録する。
公開の承認条件・停止状態は従来ルールに従う。この資料だけで自動投稿を再開しない。

## 出力形式
新規投稿画像1枚と、参照ファイル名・バージョン・生成日時・場面・品質確認結果。
不一致、参照取得失敗、構図反復の3ケースは不合格として修正する。

## 生成指示のひな型
添付主参照のLUNAと同じ顔立ちを維持し、補助参照を角度と表情の手がかりにする。
場面：{投稿に適合した場面}。時間帯：{時間帯}。服装：{服装}。
自然でラフなiPhone写真1枚。自然な肌の質感。文字・コラージュなし。
直近画像とは目線・顔の方向・カメラ高さ・手の位置を変える。
